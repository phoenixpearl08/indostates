# Indo States Health – Phased Implementation Roadmap

This document outlines the step-by-step engineering plan executing all 16 phases mandated in the Master Specification.

| Phase | Title | Key Milestones & Deliverables | Status |
| :--- | :--- | :--- | :--- |
| **Phase 0** | Research & Audit | Comprehensive website audit, verified content inventory, UX report, sitemap, architecture, and roadmap. | **Completed** |
| **Phase 1** | Design System & Visual Identity | Clean, calming medical visual identity, tokens, button variants, card layouts, dialogs, responsive header & footer. | **Next** |
| **Phase 2** | Public Website Pages | Flagship Home, About, Vision/Mission, Leadership, Doctor Directory & Individual Profiles, Departments, Diagnostic Center (MRI, CT, DEXA, Mammography, Lab), Master Health Checkup, Patient Info, Emergency, Contact, Charity, Careers, Legal. | In Plan |
| **Phase 3** | IndoCare AI Chatbot | Grounded conversational AI assistant with safety guardrails, English/Tamil/Hindi support, suggestions, appointment deep links, human fallback. | In Plan |
| **Phase 4** | Smart Omni-Search & Guided Assistant | Unified search over doctors, tests, packages, FAQs, and "I Need Help" interactive care guide. | In Plan |
| **Phase 5** | Multi-Step Appointment Booking Engine | 8-step booking wizard, slot picker, validation, double-booking prevention, unique reference codes, digital appointment pass & QR code. | In Plan |
| **Phase 6** | Patient Portal | Secure dashboard for upcoming/past bookings, pass download, rescheduling/cancellation, and family profiles. | In Plan |
| **Phase 7** | Doctor Portal | Role-protected dashboard for doctor's daily appointment queue, consultation statuses, and schedule control. | In Plan |
| **Phase 8** | Admin Portal | Comprehensive hospital admin dashboard: doctor management, department CRUD, package rates, FAQ manager, AI knowledge base manager, audit logs. | In Plan |
| **Phase 9** | Database & Full-Stack Backend | Next.js API routes, PostgreSQL / Supabase ready schemas, Zod validation, RLS policies, native local fallback persistence. | In Plan |
| **Phase 10** | External Integrations & Adapters | Google Maps embed & directions, Google Sign-in adapter, notification dispatch adapters, AI model provider interface. | In Plan |
| **Phase 11** | Emergency & Location Experience | Prominent emergency hotlines, ambulance guidance, Google Maps directions from Airport/Railway, visitor guidance. | In Plan |
| **Phase 12** | Accessibility & Multilingual Support | WCAG 2.1 AA conformance, keyboard navigation, screen reader labels, English/Tamil/Hindi language switching. | In Plan |
| **Phase 13** | SEO & Performance Optimization | Semantic HTML5, metadata, OpenGraph, JSON-LD schema (Hospital/MedicalBusiness/Physician), sitemap.xml, robots.txt. | In Plan |
| **Phase 14** | Security & Privacy Protections | Privacy-by-design, sanitization, CSRF/XSS defenses, rate-limiting, audit logging, zero hardcoded credentials. | In Plan |
| **Phase 15** | Testing & Quality Assurance | Automated route verification, form validation, booking workflow validation, AI safety guardrail tests, production build check. | In Plan |
| **Phase 16** | Deployment & Documentation | Production build validation, `.env.example`, Supabase setup guide, admin onboarding instructions, handover document. | In Plan |
