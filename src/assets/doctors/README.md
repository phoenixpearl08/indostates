# Doctor & Specialist Portraits

## Purpose
Contains authorized photographic portraits of credentialed hospital medical consultants, surgeons, and specialists.

## Status
`[HOSPITAL TO PROVIDE OFFICIAL ASSETS]`

## Recommended Specifications
- **Dimensions:** 600x800 px (3:4 portrait) or 600x600 px (1:1 square)
- **Format:** WebP or JPG, clean neutral clinical backdrop (white/light blue/studio grey)
- **File Naming Convention:** `[doctor-slug].webp` (e.g. `dr-demo-doctor-cardiology.webp`)
- **Optimization:** < 100 KB per photo

## Fallback Behavior
When an official photo is not yet provided, `DoctorPhotoPlaceholder` or `HospitalImage` displays a neutral institutional placeholder:
`"Official hospital image to be provided"`
