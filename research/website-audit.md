## 6. Audit of Existing Website Weaknesses & Gaps

| Area | Current Website State | Required Next-Gen Improvement |
| :--- | :--- | :--- |
| **Platform & Speed** | WordPress + Heavy Elementor plugin load (slow TTFB, heavy DOM). | Next.js 14+ SSR, optimized Tailwind CSS, fast interactive hydration. |
| **Booking Workflow** | A basic static form with date input, no time slots, no slot reservation, no double-booking guard. | Interactive multi-step booking engine with departments, doctors, confirmed slots, instant reference code & printable digital QR pass. |
| **Search** | Standard WP search box or none. | Smart instant search across doctors, tests, packages, departments, symptoms & FAQs with typo-tolerance. |
| **AI Capabilities** | None (Static FAQ text only). | **IndoCare AI** assistant grounded in verified hospital data, supporting English, Tamil, and Hindi, with strict clinical safety guardrails. |
| **Patient Experience** | No patient dashboard; login links redirect to external third-party software (`indo.provalan.com`). | Dedicated Patient Portal for upcoming appointments, history, digital passes, rescheduling, and family records. |
| **Doctor / Admin Portals**| Generic third-party login. | Role-protected Doctor Portal (schedule, consultations) and Enterprise Admin Dashboard (CRUD for doctors, slots, packages, AI knowledge base). |
| **Multilingual Support**| English only. | Multilingual switcher supporting English, தமிழ் (Tamil), and हिंदी (Hindi). |
| **Accessibility** | Limited keyboard navigation; contrast issues in hero banners. | Full WCAG 2.1 AA compliance, accessible ARIA landmarks, keyboard-friendly focus rings, contrast controls. |
| **Emergency Guidance** | Phone number in top header, no dedicated emergency protocol or hospital entrance instructions. | Prominent emergency banner, dedicated Emergency Information page, quick dial, maps, and ambulance dispatch protocols. |
